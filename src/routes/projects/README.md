## Adding a project

Create its `project.ts` and add it to `src/data/projects.ts`, which drives the project boxes, the
header menu and the timeline. Set `inMenu` to show it in the header menu, and `year` to show it on
the timeline.

## Naming project in project.ts

### name

Just name (ex: "Videostop"), without the "Projekt" prefix. Used in the header menu, boxes and the
timeline

### fullname

Use name and prefix (ex: "Projekt Videostop")

## Naming project in +page.svelte

### Meta title

        Just name (ex: "Videostop")

### Headline 2

        Use name and prefix (ex: "Projekt Videostop")

### Název projektu

        Just name (ex: "Videostop")
